실시간 IoT 모니터링을 위한 백엔드 아키텍처 리팩토링

주요 변경사항:
- 센서 타입별 테이블 분리 (3상 4선식/3상 3선식)
- 자동 집계 시스템 구현 (1분/15분/1시간/1일/1년)
- 원시 데이터 대신 집계 테이블 조회로 변경
- 더미 수집기 데이터 시뮬레이션 개선
- 에러 처리 및 로깅 강화

파일:
- bootstrap.py: 스키마 분리 및 마이그레이션
- aggregator.py: 백그라운드 자동 집계
- *_service.py: 집계 테이블 조회 로직
- dummy_*.py: 현실적인 데이터 생성
- settings.py: 설정 수정 및 헬퍼 메서드
- main.py: 집계기 통합

완료된 작업
- bootstrap.py: 테이블 분리 (4wire/3wire)
- aggregator.py: 자동 집계 시스템
- settings.py: ID 수정, 5초 폴링
- dummy_*_collector.py: 데이터 생성 개선
- *_service.py: 집계 테이블 조회
- main.py: 집계기 통합

예정 사항:
- modbus_router.py: 새 service 함수 연동
- env_router.py: 새 service 함수 연동  
- solar_router.py: 새 service 함수 연동
